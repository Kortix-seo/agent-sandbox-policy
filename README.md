# An open-source sandbox policy you review as a diff

Kortix is the open-source AI Operating System, and this repository is a reference project built on it. A session runs in its own sandbox, and that sandbox bounds the damage a bad command can do. What decides whether the agent may attempt the command at all is the `kortix.yaml` in this repo: two agents with short grant lists, a policy mode set to `risk`, two rules and a four-hour approval window. Approval gates you set. Off until you set them.
